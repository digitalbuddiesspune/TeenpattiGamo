# Teen Patti Muflis

Standalone Vite + React game client for **Teen Patti Muflis** (lowest hand wins).

## Environment

Copy `.env.example` to `.env` (optional; defaults shown below):

```env
VITE_API_BASE=http://localhost:4100/api
VITE_PLATFORM_GAME_ID=2
```

## Scripts

```bash
npm install
npm run dev     # runs on http://localhost:5177
npm run lint
npm run build
```
