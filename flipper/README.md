# Teen Patti Flipper

Standalone Vite + React game client for **Teen Patti Flipper** (4 cards dealt; public and folded reserve cards add joker ranks).

## Environment

Copy `.env.example` to `.env` (optional; defaults shown below):

```env
VITE_API_BASE=http://localhost:4100/api
VITE_PLATFORM_GAME_ID=2
```

## Scripts

```bash
npm install
npm run dev     # runs on http://localhost:5178
npm run lint
npm run build
```
