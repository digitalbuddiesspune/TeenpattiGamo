# Teen Patti AK47

Standalone Vite + React game client for **Teen Patti AK47** (A, K, 4, and 7 are jokers).

## Environment

Copy `.env.example` to `.env` (optional; defaults shown below):

```env
VITE_API_BASE=http://localhost:4100/api
VITE_PLATFORM_GAME_ID=2
```

## Scripts

```bash
npm install
npm run dev     # runs on http://localhost:5176
npm run lint
npm run build
```
